If, for, switch

Go has one loop keyword and no brackets around conditions. The braces are always required, even for one line.

if

        if temp > 30 {
            fmt.Println("hot")
        } else if temp > 15 {
            fmt.Println("nice")
        } else {
            fmt.Println("coat")
        }

if can run a short statement first. The variable it makes only lives inside the if and its else branches, which keeps it out of the way:

        if n, err := strconv.Atoi("42"); err == nil {
            fmt.Println("got", n)
        }
        // n and err don't exist down here

for is the only loop

The classic three-part loop: init runs once, the condition is checked before every pass, and the post statement runs after every pass. Step through it.

loop stepper ready

                        if i%2 == 0 {
                            fmt.Println(i, "even")
                        } else {
                            fmt.Println(i, "odd")
                        }
                    }
                    fmt.Println("done")

Leave parts out and the same keyword covers every other kind of loop:

    
        for count < 10 {      // a while loop
            count++
        }

        for {                  // forever. leave with break or return
            if done() {
                break
            }
        }

        for i, name := range names {   // index and value of every item
            fmt.Println(i, name)
        }

        for i := range 3 {     // Go 1.22+: 0, 1, 2
            fmt.Println(i)
        }
    

    
continue skips to the next pass, break leaves the loop.






    
switch

    
Go checks cases top to bottom and runs the first one that matches, then stops. No break needed. Pick a day and watch it look.

A switch with nothing after the keyword is a tidy chain of if/else:

    
        switch {
        case score >= 90:
            grade = "A"
        case score >= 80:
            grade = "B"
        default:
            grade = "C"
        }

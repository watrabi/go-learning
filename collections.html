Slices and maps

Slices are the list type you'll use every day. They're simple to use and a little surprising underneath, so this lesson opens one up.

Arrays, then slices

An array has a fixed length that's part of its type. [3]int and [4]int are different types. You rarely use them directly.

A slice is a small window onto an array. It holds three things: a pointer to where the window starts, its length (how many items you can see) and its capacity (how far the array goes past the start).

        a := [3]int{1, 2, 3}      // array
        s := []int{1, 2, 3}       // slice (Go makes the array for you)
        s = append(s, 4)          // slices grow
        fmt.Println(len(s), s[0], s[1:3])

Two things to take away:

    
    
        
  • Always write s = append(s, x). When the array is full, append makes a new, bigger one (roughly double) and copies everything across. The old s would still point at the old array.
    • 
        
  • Slices of the same array share memory. t := s[:2] doesn't copy anything. Change t[0] and s[0] changes too. Use slices.Clone or copy when you want an independent copy.
    • 
    

    

        
make: If you know roughly how big a slice will get, make([]int, 0, 100) gives it length 0 and room for 100, so append never has to copy.

    






    
Maps

    
A map stores values by key, like a dictionary or hash table in other languages.

    
        ages := map[string]int{"ana": 31, "bo": 25}
        ages["cy"] = 40            // add or overwrite
        delete(ages, "bo")         // remove
        age, ok := ages["dee"]     // ok is false: "dee" isn't there, age is 0

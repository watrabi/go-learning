Hello, Go

Go is a small, fast, compiled language from Google. It was made so big teams could write simple code that builds in seconds. This lesson gets a program running.

Your first program

Every Go file starts by saying which package it belongs to. A program you can run lives in package main and starts at func main(). Click each line below to see what it does.

anatomy of a go file click a line
                package main

                import "fmt"

                func main() {
                    fmt.Println("hello, world")
                }

Running it

The go command does almost everything: run, build, format, test and fetch packages. Press the buttons to see what each one does in a terminal.

the go command
$

A Go project is a module: a folder with a go.mod file naming it. Make one with go mod init before anything else.

Three rules that surprise people

Capital letters are public. A name starting with an uppercase letter (Println, Pi) can be used from other packages. Lowercase names are private to their package. There's no public keyword.

Unused things don't compile. An import or local variable you never use is an error, not a warning. It keeps code tidy, and it will annoy you for about a week.

The formatter decides. go fmt rewrites your code into the one standard layout. Tabs for indents, braces on the same line. Everyone's Go looks the same, which makes reading other people's code easy.

        package main

        import (
            "fmt"
            "strings"
        )

        func main() {
            name := "gopher"
            fmt.Println("hello,", strings.ToUpper(name))
            fmt.Printf("%s has %d letters\n", name, len(name))
        }
